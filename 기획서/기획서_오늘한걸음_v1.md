# 「오늘한걸음」 기획서 초안 v1 (가칭)
### 방 안의 첫 일 — AI를 가르치며 세상으로 나오는 고립·은둔 청년 회복 플랫폼

> 로그라인: **방 밖으로 나오기 어려운 청년이, 방 안에서 AI 학습데이터를 다루는 '10분짜리 첫 일'로 하루를 세우고, 첫 수입과 일 경험을 쌓아 세상으로 나온다.**

---

## 1. 아이디어 개요

### 배경: 회복 지원은 시작됐지만, 끝까지 가는 청년이 드물다
- 고립·은둔 청년 지원은 국가 과제가 됐다. 청년미래센터가 2026년 9월부터 전국 17개 시도로 확대된다(8/11 범정부 자살예방 대책). 서울시는 서울에만 고립·은둔 청년이 약 24만 명(은둔 5.4만 + 고립 19.4만)이라고 추정한다.
- 그런데 끝까지 가는 청년이 드물다. 청년미래센터 사례관리 종결자 152명을 보면 다음과 같다(국민일보, 2026.9.29).
  - **77%가 중도에 스스로 그만뒀다.**
  - 목표를 달성한 청년은 **10.5%** 뿐이다.
  - 그만둔 청년의 **78.6%는 사후관리를 받지 못했다.**
  - 반면 **70%는 스스로 센터를 찾아왔다.** 나오고 싶은 마음은 있었다는 뜻이다.
- 기존 온라인 회복 프로그램(서울시 비대면 '서울In챌린지', 외출 '서울Go챌린지' 등)은 "햇볕 쬐기 → 방 청소 → 동네 산책" 같은 **생활 미션**이 중심이다. 진로·취업 프로그램도 있지만 대부분 센터에 나와야 하는 대면 프로그램이다. 대면 공포가 큰 청년에게 '외출'과 '일' 사이의 간격은 여전히 너무 크다.

### 한 줄 요약
「오늘한걸음」은 생활 미션과 사회 진입 사이에 **'방 안의 첫 일'** 이라는 다리를 놓는다. AI가 청년의 그날 컨디션에 맞춰 **AI 학습데이터 작업(사진 분류, 문장 검수 등)을 10분 단위 일감**으로 쪼개 주고, 쌓인 일 기록을 일경험과 취업으로 연결하는 매일 쓰는 회복 플랫폼이다.

## 2. 아이디어 상세 내용 및 차별성

### 사용 시나리오 (누가 · 언제 · 얼마나 자주)
| 항목 | 내용 |
|---|---|
| 누가 | 고립·은둔 청년 (청년미래센터·지자체 사업 참여자 및 자발적 가입자). 보조 사용자: 가족, 담당 상담사 |
| 언제 | 기상 후 컨디션 체크 → 오후 일감·미션 → 자기 전 한 줄 회고 |
| 얼마나 자주 | 매일 2~3회, 회당 10~30분 |

### 하루 장면 (가상 예시): 지훈 씨, 27세, 은둔 2년차
| 시간 | 장면 |
|---|---|
| 11:00 | 컨디션 체크 "😐 보통". AI: "오늘은 가볍게 갈게요. 일감 10분 + 햇볕 미션 하나." |
| 14:00 | **오늘의 일감**: 길거리 사진 50장에서 '횡단보도' 고르기 (자율주행 학습데이터). 10분 완료, 정확도 96%. "오늘 1,700원 벌었어요(작업비 + 일경험 수당). 이번 주 누적 7,500원." |
| 14:15 | AI: "어제보다 집중 시간이 늘었어요. 내일은 20분짜리 해 볼까요?" (실패한 날에는 5분짜리로 쪼갬) |
| 16:00 | 생활 미션: 창문 열고 하늘 사진 한 장 |
| 22:00 | 한 줄 회고. 주 1회 본인 동의 범위 안에서 상담사에게 요약 공유 |
| 4주 뒤 | "누적 작업 18시간, 정확도 상위 20%." 일 기록이 **'첫 이력서'** 로 정리되고, 청년미래센터 일경험 프로그램으로 연결 제안 |

### 핵심 기능
**① 방 안의 첫 일 (핵심)**

| 단계 | 내용 | 보상 |
|---|---|---|
| Lv1 맛보기 | 1~5분 초간단 분류 작업 | 포인트 |
| Lv2 첫 일감 | 10분 단위 일감 세트 | 소액 현금 |
| Lv3 꾸준한 일 | 30분 이상, 검수 같은 상위 작업 | 작업 단가 + 공공 일경험 수당 보전 |
| Lv4 연결 | 누적 기록으로 '첫 이력서' 자동 생성, 일경험·취업 프로그램 연결 | 사회 진입 |

- AI가 하는 일
  1. **난이도·분량 자동 조절**: 그날 컨디션과 최근 성공률을 보고 일감 양을 정한다. 실패하면 더 잘게 쪼갠다.
  2. **일 기록 포트폴리오화**: 작업 시간, 정확도, 꾸준함을 '일 경험'으로 정리한다. 공백기가 있는 이력서를 대신할 근거가 된다.
  3. **이탈 징후 감지**: 응답 패턴이 무너지면 상담사에게 알린다(본인 동의 시).

**② 끊어져도 이어지는 '재연결 약속' (보조)**
- 시작할 때 청년이 스스로 동의한다. 예: "연락이 끊기면 2주 뒤, 한 달 뒤에 가볍게 안부를 물어도 돼요."
- 중도 이탈 후에도 AI가 부담 없이 다시 노크하고, 원하면 센터로 재연결한다.

**③ 매일 쓰는 가족 코치 (보조)**
- 부모교육(서울시 오프라인 주 1회, 온라인 콘텐츠)은 일반 교육이지만, 갈등은 매일 그 집만의 상황에서 일어난다. 부모용 AI가 그날 쓸 말을 제안한다. 예: "'언제 나올래?' 대신 '문 앞에 귤 두고 갈게'."
- 청년이 동의하면 구체 내용 없이 진척만 공유한다. 예: "오늘 일감 완료." 부모는 칭찬할 거리를 얻는다.

### 차별성
| | 기존 회복 프로그램 (서울시 In·Go챌린지, 센터 프로그램) | 정신건강 앱 (트로스트, 마인드카페 등) | 데이터 라벨링 플랫폼 | **오늘한걸음** |
|---|---|---|---|---|
| 회복 단계 | 생활 미션 → 외출 → (대면) 진로·취업 프로그램 | 상담·감정 기록 | 해당 없음 | 생활 미션 → **방 안의 첫 일 → 일경험** |
| 난이도 조절 | 정해진 챌린지 | 해당 없음 | 일반 작업자 기준 | **AI가 컨디션 맞춤으로 쪼갬** |
| 첫 수입·일 기록 | ✗ | ✗ | 수입만 | **수입 + 포트폴리오 + 공공 연결** |
| 이탈자 | 관리 공백 (이탈자 78.6% 사후관리 없음) | 해당 없음 | 해당 없음 | **재연결 약속** |
| 가족 | 부모교육 (오프라인·온라인 콘텐츠) | ✗ | ✗ | **매일, 그 집 상황에 맞춘 가족 코치** |

**핵심 차별점**: 은둔 청년을 '돌봄 대상'이 아니라 **'AI를 가르치는 사람'** 으로 다시 세운다. 대면 없이 가능한 일, 작고 확실한 성취, 첫 수입이 회복의 동기가 된다.

## 3. 실현 가능성
- **일감은 이미 존재한다**: 데이터 라벨링은 자격 없이 재택으로 가능한 작업이고, 국가직무능력표준(NCS)에도 등록된 직무다. 국내 최대 플랫폼 크라우드웍스에만 활성 작업자가 약 68만 명이다.
- **취약계층 연계 선례가 있다**
  - 과기정통부·NIA의 AI 학습용 데이터 구축 사업은 2020년부터 수행기관에 직접 고용을 의무화하고 크라우드소싱 비중을 평가에 반영해, 경력단절 여성·장애인·은퇴자 등 취약계층 일자리를 만들어 왔다.
  - 인천시는 크라우드웍스·한국노인인력개발원과 손잡고 '시니어 데이터 라벨러' 일자리를 만들었고, 서울시는 발달장애인 데이터 라벨러를 양성했다.
  - → 같은 구조를 **고립·은둔 청년**에게 처음 적용한다.
- **일감 확보 경로**: 1단계는 민간 크라우드소싱 플랫폼 제휴로 시작한다. 2026년 공공 데이터 구축 사업(66억 원, 10개 과제)은 고난도 추론 데이터 중심이라 초보 작업에 바로 맞지 않으므로, 향후 공공 사업의 크라우드소싱 물량 일부를 '사회적 가치 배정'으로 받는 것은 정책 제안으로 둔다.
- **기술**
  - 난이도·분량 조절, 이탈 징후 감지: 사용 기록 기반 개인화 모델
  - 대화·코칭·포트폴리오 작성: 국내 독자 AI 파운데이션 모델 API
  - 위기 표현 감지: 위험 키워드·문맥 분류 → 109 및 담당 상담사 연계
- **운영 구조**: 청년미래센터(전국 17개 시도)가 참여자를 연결하고, 플랫폼은 센터 사이의 '매일'을 맡는다. 새 기관을 만들지 않고 기존 지원 체계에 붙는다.
- **비용 대비 효과**: 상담사 1명이 관리할 수 있는 인원이 늘고(매일 기록과 이탈 알림), 이탈률이 줄면 이미 투입된 사례관리 비용의 효과가 커진다. 작업 결과물은 실제 AI 학습데이터로 쓰여 사회적 가치도 남긴다.

## 4. 기대 효과 및 파급력
- **청년**: 대면 부담 없이 '하루의 틀'과 첫 수입, 증명 가능한 일 경험을 얻는다.
- **지원 기관**: 77%에 이르는 중도 이탈을 줄이고, 이탈자도 다시 이어 붙일 수 있다.
- **가족**: 매일의 소통 방법을 얻고 갈등이 줄어든다.
- **사회**: 고립·은둔으로 인한 사회경제적 비용을 줄이고, AI 학습데이터 인력 풀을 넓힌다.
- **확산**
  - 1단계: 청년미래센터 참여 청년
  - 2단계: 장기 취업 준비생, 경력 단절자 등 '일의 공백'이 긴 사람
  - 3단계: 조기 퇴직 중장년 등 생애 전환기 고립 위험군

## 5. AI 윤리 및 안전성
| 위험 | 대응 |
|---|---|
| 값싼 노동 착취로 변질 | 초보 라벨러의 실제 시급은 4,000~6,000원 수준으로 최저임금에 못 미친다. 그래서 **작업 단가 + 공공 일경험 수당 보전으로 최저임금 수준을 보장**하는 것을 필수 조건으로 둔다. 일감 양 강요 금지, 언제든 쉬기 가능 |
| 단순 라벨링 일감 감소 | AI 자동 라벨링이 늘면서 단순 작업은 줄어드는 추세다. 일감 범위를 **사람의 판단이 필요한 작업**(한국어 답변 자연스러움 평가, 결과 검수 등)으로 넓혀 둔다 |
| 정신건강에 해로운 작업 | 폭력·혐오 콘텐츠 검수 같은 유해 작업은 일감에서 원천 제외 |
| 위기 상황 | 위험 표현 감지 시 109 자살예방상담과 담당 상담사로 즉시 연결. AI는 상담사를 대체하지 않음 |
| 민감정보 노출 | 상담사·가족 공유는 본인이 범위를 선택. 가족에게는 진척 여부만 공유하고 대화 내용은 공유하지 않음 |
| 재연결의 개인정보 문제 | 본인이 사전 동의한 범위와 기간에서만 연락. 현행 규정과의 정합성은 '본인 동의 기반 재연결' 제도 개선으로 제안 |
| AI 생성물 표시 | AI가 만든 메시지와 리포트에 AI 작성임을 표시 (AI기본법) |

## 6. 맺음말
「오늘한걸음」은 방 밖으로 나오기 어려운 청년에게 "나와라"가 아니라 **"방 안에서 시작할 수 있는 일"** 을 건넨다. AI를 가르치는 10분이 하루의 틀이 되고, 첫 수입이 되고, 세상으로 나가는 첫 이력이 된다. 향후 청년미래센터 1곳과 시범 운영해 중도 이탈률과 일경험 연계율 변화를 검증하고자 한다.
